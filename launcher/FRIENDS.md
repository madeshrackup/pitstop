# Pitstop for friends

Private Mario Kart Wii online with separate saves. Your original game dump is never modified.

## You need

1. **Dolphin** emulator installed
2. Your own **NTSC-U (RMCE01) rev 00** Mario Kart Wii dump (WBFS or ISO)
3. Network access to the Pitstop server (`psmk.duckdns.org`) **and** to download the pack (GitHub / host URL)

## Mac

1. Open `Pitstop.app` (first time: right-click → Open if Gatekeeper warns)
2. Browse to Dolphin and your MKWii dump
3. **Setup / Update** — downloads the pack, then builds a cache (few minutes first time)
4. **Play**

## Windows

1. Run `Pitstop.exe` (SmartScreen may warn — Run anyway; unsigned for now)
2. Browse to Dolphin.exe and your dump
3. **Setup / Update**, then **Play**

## Notes

- Pack updates come from the host URL baked into the app — you usually do **not** need a new `.app` when the patch changes
- Pitstop uses its own Dolphin user folder (separate licenses/saves)
- Force 150cc + unlock-all are baked into the pack
- Do not share or redistribute game dumps
