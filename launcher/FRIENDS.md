# Pitstop for friends

Private Mario Kart Wii online with separate saves. Your original game dump is never modified.

## You need

1. **Dolphin** emulator installed
2. Your own **NTSC-U (RMCE01) rev 00** Mario Kart Wii dump (WBFS or ISO)
3. Network access to the Pitstop server (`psmk.duckdns.org`) **and** to download the pack (GitHub)

## First launch

1. Open Pitstop (Mac: right-click → Open if Gatekeeper warns; Windows: Run anyway if SmartScreen warns)
2. **Allow** Pitstop to create its own save/settings folders (required)
3. Confirm **Dolphin** (auto-detected when possible — green = good) and pick your **MKWii dump**
4. Pitstop downloads the latest pack and finishes setup
5. **Play** — create a license in-game, then use **Licenses** in Pitstop for rename / Miis / primary

## Later

- **Check for updates** — downloads a newer pack if one exists (or says you’re already up to date)
- Miis sync one-way from Dolphin’s Mii Channel into Pitstop automatically

## Notes

- Pack updates come from the host URL baked into the app — you usually do **not** need a new app build when only the patch changes
- Pitstop uses its own Dolphin user folder (separate licenses/saves)
- Force 150cc + unlock-all are baked into the pack
- Do not share or redistribute game dumps
